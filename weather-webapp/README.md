# Weather Mini App

Веб-приложение для отображения текущей погоды и прогноза на 5 дней.

## Основной функционал

- Отображение текущей погоды с детальной информацией (температура, влажность, давление, видимость, скорость ветра)
- Прогноз погоды на 5 дней с возможностью просмотра детальной информации по каждому дню
- Поиск городов с автодополнением
- Определение местоположения через геолокацию браузера
- Переключение между светлой и тёмной темой
- Поддержка русского и английского языков
- Визуальные эффекты погоды (дождь, снег, туман)
- Адаптивный дизайн для мобильных устройств и десктопов

## Технологический стек

- React 18
- TypeScript
- Vite
- SCSS Modules для стилизации
- React i18next для интернационализации
- OpenWeatherMap API для получения данных о погоде

## Установка зависимостей

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

## Сборка для продакшена

```bash
npm run build
```

## Деплой

Приложение автоматически деплоится на GitHub Pages при пуше изменений в ветку main через GitHub Actions.
