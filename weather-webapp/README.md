# Weather Mini App

Веб-приложение для просмотра погоды с красивым интерфейсом и погодными эффектами.

## Функции

- 🌤️ Текущая погода с детальной информацией
- 📅 Прогноз на 5 дней
- 🔍 Поиск городов с автодополнением
- 🌍 Поддержка геолокации
- 🌙 Переключение темы (светлая/тёмная)
- 🌐 Мультиязычность (русский/английский)
- ❄️ Погодные эффекты (дождь, снег, туман)
- 📱 Адаптивный дизайн

## Технологии

- React 18
- TypeScript
- Vite
- SCSS Modules
- React i18next
- OpenWeatherMap API

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```
